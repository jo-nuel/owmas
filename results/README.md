# Experiment outputs

These files were generated by `scripts/run_experiment.py` from the frozen data and registered configuration.

## Main evidence

- `performance_metrics.csv` contains the full-sample performance table.
- `h1_sharpe_tests.csv` contains the paired Sharpe comparisons.
- `h2_risk_tests.csv` contains the drawdown and volatility comparisons.
- `h3_rolling_summary.csv` and `h3_rolling_tests.csv` contain the rolling Sharpe results.
- `h4_profile_tests.csv` contains the weighting-profile comparisons.
- `subperiod_metrics.csv`, `holdout_metrics.csv`, and `sensitivity_metrics.csv` contain the robustness results.
- `equity_curves.png`, `drawdowns.png`, and `rolling_sharpe.png` are the figures used in the thesis.
- `run_metadata.json` records the input, code, and output hashes for the run.

Do not edit these files by hand. Regenerate them with the experiment script, then run `scripts/validate_experiment_outputs.py`.
